# Nahjinst

> Nahjinst is a modern web application for the An-Nahj Islamic Institute, built with Next.js, TypeScript, and a modular component architecture. The project’s main purpose is to provide high-quality Islamic education and resources to individuals of all backgrounds. It is structured for rapid development, scalability, and maintainability.

## Project Mission

An-Nahj Islamic Institute is an islamic institute dedicated to promoting a deeper understanding of Islam and its teachings, while fostering a sense of community and spiritual growth among students .

## Overview

Nahjinst leverages the latest features of Next.js, including the App Router, TypeScript, and modular component architecture. It is structured for rapid development and easy maintainability.

## Features

- Fast, optimized Next.js app with modular components
- TypeScript for type safety
- Customizable styling (CSS/PostCSS)
- Ready for deployment (Vercel, custom servers, etc.)

## Educational Focus

The institute offers structured programs in Qur’an, Arabic, Hadith, and Fiqh, designed to help students learn with clarity and discipline.

## Getting Started

1. **Install dependencies:**

   ```bash
   npm install
   # or
   yarn install
   ```

2. **Run the development server:**

   ```bash
   npm run dev
   # or
   yarn dev
   ```

3. **Open your browser:**
   Visit [http://localhost:3000](http://localhost:3000) to view the app.

## Available Scripts

- `dev` – Start the development server
- `build` – Build for production
- `start` – Start the production server
- `lint` – Run ESLint for code quality
